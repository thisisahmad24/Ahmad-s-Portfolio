# Ahmad Hassan — Portfolio

A responsive personal portfolio for Ahmad Hassan, a software engineer focused on AI/ML, backend development, full-stack applications, and software quality assurance.

## Built with

- React 19
- Vite
- CSS design system with responsive layouts and light/dark themes
- React Icons

## Portfolio sections

- Intro and professional links
- About and education
- Technical skills
- Selected projects: VIRQA, SnapSave Pro, Sentiment Analysis, and QA Automation Portfolio
- Professional experience
- Contact links and résumé download

## Run locally

```bash
git clone https://github.com/thisisahmad24/Ahmad-s-Portfolio.git
cd Ahmad-s-Portfolio
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```
